# ConfluenceAI — بوت إشارات التداول المؤسسي (كريبتو + ذهب)

محرك كمّي بلغة Python يحلل **أفضل 20 زوج عقود دائمة على Binance** و**الذهب XAUUSD** عبر أربع مدارس (SMC/ICT، السيولة وVWAP، البرايس أكشن والدايفرجنس، فلتر النظام والفريمات)، ويعطي تقييم **0–100** (الحد الأدنى 75) ويشترط **عائد/مخاطرة ≥ 1:2**، ثم يرسل الإشارة لتيليجرام بالعربية ويتابع الصفقة لحظياً. ويأتي معه **لوحة ويب وتطبيق PWA** قابل للتثبيت على الجوال.

> ⚠️ **تنبيه مهم:** إشارات تعليمية وليست نصيحة مالية. لا يوجد أي ضمان للربح. شغّل `backtest.py` على بياناتك الحقيقية وجرّب على حساب تجريبي قبل أي مخاطرة برأس مال حقيقي.

## ما الذي تم إصلاحه في هذه النسخة (v2)

### أخطاء منطقية خطيرة
| المشكلة في النسخة الأصلية | الإصلاح |
|---|---|
| الإشارات تُبنى على **شمعة غير مكتملة** (تتغير وتُلغي نفسها) | تُحذف الشمعة الجارية تلقائياً (`DROP_FORMING_CANDLE`) |
| الرسالة تقول «انقل الوقف للدخول» لكن الكود يستخدم **الوقف الأصلي** فعلياً | بعد الهدف الأول يصبح الوقف الفعلي = سعر الدخول، وتُحسب النتيجة بدقة |
| تتبع الصفقة بآخر سعر فقط → **يفوّت الفتائل** التي تضرب الوقف/الهدف بين فحصين | يُفحص أعلى/أدنى سعر منذ آخر فحص من شموع 1 دقيقة، مع ترتيب متحفظ (الوقف أولاً عند التعارض) |
| المراقبة (كل 30ث) **تتوقف أثناء المسح** الطويل | المراقبة في خيط مستقل مع إعادة تشغيل تلقائية |
| تُسجَّل الصفقة في القاعدة **حتى لو فشل إرسالها** لتيليجرام | تُرسل أولاً، وإن فشلت يُتراجع عن تسجيلها |
| صفقات معلقة **لا تنتهي أبداً** وتحجب الرمز | انتهاء صلاحية (`PENDING_EXPIRY_HOURS`) + إلغاء إن ركض السعر للهدف دون تفعيل |
| لا حد للصفقات المتزامنة المتشابهة | `MAX_OPEN_TRADES` + فترة تبريد `SIGNAL_COOLDOWN_HOURS` |
| `EMA200` تعطي NaN عند قلة الشموع فيُحكم بنظام «عرضي» خطأً | يُشترط ≥210 شمعة، وإلا يُتخطى الرمز |

### جودة الإشارة
- قمم/قيعان محورية أدق (بدون تكرار الأسعار المتساوية).
- RVOL يقارن بمتوسط **سابق** بدل تضمين الشمعة نفسها.
- سحب السيولة يُعتمد فقط إن بقي الإغلاق الحالي داخل النطاق.
- حدود للوقف (0.35–4 ATR) وسقف للأهداف الهيكلية، وتحقق من ترتيب المستويات بعد التقريب.
- حجم التيك: إصلاح خطأ يعطي دقة خاطئة لبعض الأزواج.

### الأمان والاعتمادية
- **تسريب التوكن:** تتبّع الأخطاء (traceback) من `requests` يحوي رابط تيليجرام مع التوكن؛ أصبح يُحجب الآن.
- إزالة النوم بعد آخر محاولة فاشلة، ورسالة بديلة نصية نظيفة عند رفض HTML، و`reply_parameters` الحديث.
- النموذج الافتراضي لـ Claude تحديث إلى `claude-sonnet-4-6` (القديم `claude-3-5-sonnet-latest` متقاعد).
- تنسيق الأسعار حسب دقة الأداة الفعلية (لا أرقام علمية للعملات الصغيرة).

### جديد
- `api_server.py` + `web/` : لوحة ويب RTL وتطبيق PWA (منحنى R، الصفقات الجارية، الأداء).
- `backtest.py` : اختبار تاريخي Walk-forward بنفس إدارة الصفقة الحية.
- `tests/` : 27 اختباراً تعمل **دون إنترنت**.
- `Dockerfile` و`docker-compose.yml`.

## التشغيل

```bash
python3 -m venv .venv && source .venv/bin/activate      # ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # ضع TELEGRAM_BOT_TOKEN و TELEGRAM_CHAT_ID
python main.py
```
افتح اللوحة: **http://127.0.0.1:8080**

### بـ Docker
```bash
cp .env.example .env   # املأ التوكن و API_TOKEN (إلزامي داخل الحاوية)
docker compose up -d --build
```

## تطبيق الجوال (PWA)
1. انشر اللوحة خلف **HTTPS** (مثلاً Caddy أو Nginx + Let's Encrypt) — المتصفح يشترطه للتثبيت.
2. افتح الرابط من الجوال ← **Android:** «تثبيت التطبيق» — **iPhone:** مشاركة ← «إضافة إلى الشاشة الرئيسية».
3. من ⚙ داخل اللوحة أدخل `API_TOKEN`.

مثال Caddy كامل:
```
signals.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

## الاختبارات والباك-تيست
```bash
python -m unittest discover -s tests -v
python backtest.py --csv data/BTCUSDT_1h.csv --symbol BTCUSDT --tick 0.1
python backtest.py --exchange BTC/USDT:USDT --bars 8000 --min-score 70
```
الباك-تيست يُظهر نسبة النجاح وصافي R ومعامل الربحية وأقصى تراجع. **اضبط `MIN_CONFLUENCE_SCORE` بناءً على نتائجه لا بالتخمين.**

## ملاحظات صريحة
- على بيانات عشوائية صرفة لا تُنتج العتبة 75 إشارات تقريباً (هذا مقصود: الانتقائية). تردد الإشارات الحقيقي وأداؤها يُقاسان بالباك-تيست على بياناتك.
- بيانات الذهب من `yfinance` (عقود `GC=F`) غير مرخّصة للإنتاج ولها تأخير؛ استخدم TwelveData للدقة.
- ملفات قالب React الفارغ القديمة نُقلت إلى `_legacy_react_scaffold/` (اللوحة الجديدة لا تحتاج أي بناء).
